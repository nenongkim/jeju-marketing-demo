# 제주 구좌 음식점 평가용 프로토타입

https://nenongkim.github.io/jeju-marketing-demo/

화면과 가공한 지역 집계만 게시합니다. 신청서·원본 데이터·실제 사용자 평가 기록은 포함하지 않습니다.
첫 화면의 계정 정보 채우기와 로그인을 사용합니다. 시연용 역할 선택이며 실제 인증이 아닙니다. 계획과 실행 기록은 이용자의 브라우저에만 저장되며 서버에 전송하지 않습니다. 평가자는 내보낸 파일과 별도 평가 양식을 전달해야 합니다.

분석 원천: https://data.ijto.or.kr (regSn 21, 27, 39, 48)
실제 사업체 효과는 미측정입니다.

검증된 원본 main 변경이 자동 반영됩니다. 게시 버전은 release.json에서 확인합니다.
